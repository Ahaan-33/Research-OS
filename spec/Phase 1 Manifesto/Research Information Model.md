# Research Operating System
# Research Information Model

This document defines the entities that comprise the Research State.

It does not define relationships between entities. See [[Relationship Ontology]].

---

## Research State

The Research State is a collection of scientific objects.

Objects possess intrinsic meaning.

Relationships produce scientific understanding.

---

## Scientific Object

A Scientific Object is the smallest independently meaningful unit of research.

Objects are atomic.

Objects may be revised, superseded or related, but should not contain multiple independent ideas.

---

## Object Identity

Each object represents one concept.

Identity remains stable regardless of:

- organisation
- location
- representation
- visualisation

An object exists independently of how it is viewed.

---

## Object Types

The information model is extensible.

Typical object types include:

- Observation
- Question
- Hypothesis
- Experiment
- Dataset
- Analysis
- Result
- Interpretation
- Decision
- Implementation
- Literature
- Reference

Types describe the role of an object rather than its storage.

---

## Objects are Immutable

An object records knowledge at a particular point in time.

Scientific understanding evolves by creating new relationships or superseding previous objects rather than rewriting history.

See:
- [[Knowledge Evolution]]

---

## Objects are Context Independent

Objects should remain meaningful outside the context in which they were created.

Context is represented through relationships rather than duplication.

See:
- [[Relationship Ontology]]

---

## Objects are Reusable

The same object may participate in many independent lines of reasoning.

Knowledge should therefore never be duplicated to satisfy different organisational needs.

See:
- [[Organisational Spaces]]

---

## Minimality

Objects should be as small as possible while remaining scientifically meaningful.

Smaller objects produce:

- greater reuse
- richer relationships
- finer provenance
- better synthesis

Atomicity is preferred over convenience.
