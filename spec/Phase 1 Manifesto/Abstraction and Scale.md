# Research Operating System
# Abstraction and Scale

Scientific knowledge can be viewed at multiple semantic scales.

Abstraction changes resolution without changing meaning.

---

## Abstraction

An abstraction compresses multiple Scientific Objects into a higher-level concept.

Higher abstractions expose structure.

Lower abstractions expose detail.

---

## Scale

Every concept exists within a hierarchy of semantic scales.

For example:

```
Cell
    ↓
Mitochondrial Network
    ↓
Fragment
    ↓
Measurement
```

Each level describes the same system at different resolutions.

---

## Navigation

Movement between abstractions should be continuous.

Researchers should be able to:

- zoom in
- zoom out
- expand
- collapse

without changing context.

---

## Progressive Disclosure

Higher abstractions expose only information necessary for the current level of reasoning.

Lower-level details remain accessible but hidden until required.

---

## Emergence

Higher abstractions describe properties that do not exist in individual objects.

Emergent concepts arise from relationships between many objects.

See:
- [[Relationship Ontology]]

---

## Stability

Changing abstraction should never change scientific meaning.

Only the amount of visible detail changes.

---

## Abstraction is Contextual

The appropriate level of abstraction depends upon the scientific question.

Different problems require different semantic resolutions.
