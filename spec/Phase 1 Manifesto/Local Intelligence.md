# Research Operating System
# Local Intelligence

This document defines the role and constraints of computational intelligence within the Research Operating System.

Artificial intelligence is an implementation detail, not a source of scientific understanding.

See:
- [[First Principles]]
- [[Cognitive Philosophy]]

---

## Purpose

Computational intelligence exists to reduce mechanical effort.

It assists:

- retrieval
- indexing
- navigation
- semantic similarity
- recommendation

It does not perform scientific reasoning.

---

## Local First

All computational intelligence executes locally.

The system remains fully functional without:

- internet access
- remote services
- cloud infrastructure

Knowledge never leaves the local machine.

---

## No Cloud Dependence

The Research Operating System has no mandatory online components.

Core functionality must not depend upon:

- cloud-hosted language models
- external APIs
- subscriptions
- online authentication
- telemetry

Offline operation is a design requirement.

---

## Computational Assistance

Computational intelligence operates on representations of knowledge rather than scientific meaning.

Examples include:

- full-text indexing
- keyword extraction
- statistical similarity
- semantic search
- graph traversal
- recommendation

Scientific interpretation remains the responsibility of the researcher.

See:
- [[Relationship Ontology]]
- [[Organisational Spaces]]

---

## Determinism

Equivalent input should produce equivalent output.

Algorithms should be:

- deterministic
- reproducible
- inspectable

The behaviour of the system should remain understandable to the researcher.

---

## Computational Minimalism

Use the simplest adequate algorithm.

Prefer:

- symbolic methods
- statistical methods
- graph algorithms
- deterministic heuristics

Avoid unnecessary model complexity.

Machine learning is optional infrastructure rather than a foundational dependency.

---

## Modular Intelligence

Search, indexing and recommendation engines are independent modules.

Replacing an implementation must not affect:

- the Research State
- Scientific Objects
- Relationships
- provenance

Knowledge is independent of computation.

See:
- [[Research Information Model]]
- [[Relationship Ontology]]

---

## Privacy

The Research State belongs entirely to the researcher.

No scientific knowledge is transmitted to external systems without explicit user action.

Privacy is the default.

---

## Longevity

The Research Operating System should remain usable regardless of the availability of external services.

Scientific knowledge must outlive any individual software, model or provider.
