# ADR-0001: Monorepo with pnpm workspaces

## Status

Accepted

## Context

_Reference Implementation Strategy_ (vault, Phase 6 Doc 4) fixes two packages for v0: a headless core library (`@ros/core`) and an Obsidian plugin shell (`@ros/obsidian-plugin`), with the plugin depending on the core and the core depending on nothing UI-related. Both live in one repository and are developed, versioned, and tested together for the lifetime of the reference implementation — there is no case in v0 where either package is released or consumed independently of the other.

## Decision

Single repository, pnpm workspaces. `pnpm-workspace.yaml` lists `packages/*`. Workspace-protocol (`workspace:*`) internal dependencies — `@ros/obsidian-plugin` depends on `@ros/core` via `"workspace:*"`, resolved locally, never through the npm registry during development.

## Why pnpm over npm/yarn workspaces or a separate-repos approach

- **Separate repositories:** rejected outright. It would force publishing `@ros/core` before the one thing that consumes it can be built against a real version, adding release-process overhead the reference implementation has no use for yet (Doc 17, Section 6, treats publishing as a deferred decision).
- **npm/yarn workspaces:** viable, not chosen. pnpm's strict node_modules layout (no phantom dependencies) is the concrete reason it wins here: it structurally prevents `@ros/obsidian-plugin` from accidentally resolving a transitive dependency that happens to be hoisted, which is the same class of "boundary enforced by absence, not convention" preference already used throughout the architecture (see ADR-0004). This is a correctness property for this specific repo, not a general pnpm endorsement.

## Consequences

- Contributors need pnpm installed (pinned via `packageManager` field in root `package.json`, honored by Corepack).
- Every package gets its own `package.json`; shared dev dependencies (TypeScript, ESLint, Vitest) live at the workspace root and are hoisted intentionally via pnpm's root install, not duplicated per package.
