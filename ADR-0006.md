# ADR-0006: `tsc` project references for `@ros/core`; `esbuild` for `@ros/obsidian-plugin` bundling

## Status
Accepted

## Context
No prior document fixes how TypeScript is compiled. `@ros/core` is consumed both by its own test suite (ADR-0005) and by `@ros/obsidian-plugin`; the plugin must ship as a single bundled `main.js` with no unresolved `node_modules` imports at runtime (Obsidian loads one file, does not run a package manager). These are two different compilation problems.

## Decision
- `@ros/core`: compiled with `tsc` alone (TypeScript project references, `composite: true`), emitting `.js` + `.d.ts` to `dist/`. No bundler — a library consumed only by another package in the same workspace (via `workspace:*`, ADR-0001) gains nothing from bundling and loses source-map-per-file debuggability.
- `@ros/obsidian-plugin`: bundled with `esbuild` (single entry `src/main.ts` → `main.js`, CJS, `external: ['obsidian', 'electron']` since Obsidian provides those at runtime). `esbuild` is the de facto standard for Obsidian plugins (used by Obsidian's own sample plugin) and its speed matters on the plugin's edit-reload-test loop.

## Why not one tool for both
A bundler on `@ros/core` would produce a single opaque file, defeating `tsc`'s per-module `.d.ts` output that `@ros/obsidian-plugin` (and ADR-0004's boundary, which relies on real module paths for its lint rule) depends on. `tsc` alone cannot produce a single dependency-free bundle for the plugin. Neither tool covers both jobs; using one throughout would force a worse fit on one package to save configuring a second tool.

## Consequences
- Root `tsconfig.base.json` holds shared compiler options; each package's `tsconfig.json` extends it.
- `pnpm build` (root) runs `tsc -b` then `esbuild` for the plugin, in that order (plugin bundling depends on `@ros/core`'s `dist/`).
- `@ros/obsidian-plugin` depends on `@ros/core` via `workspace:*` for types/dev, but esbuild inlines `@ros/core`'s compiled JS into the plugin bundle at build time — no runtime `node_modules` resolution needed once shipped.
